03 — 后端模块 / BACKEND MODULE MAP
CORE server.js
HTTP 服务器核心。静态资源服务、路由分发、Setup 模式检测、配置热监听（fs.watch openclaw.json）。零依赖 HTTP server，仅依赖 ws 模块。
server.js — 396 行
CORE ws-client.js
Gateway WebSocket 客户端。JSON-RPC 协议握手，sessions.subscribe 事件订阅，心跳保活（25s ping），指数退避自动重连（3s~30s），session polling 降级方案。
ws-client.js — 275 行 / dep: ws@^8.20.1
proxy.js
Gateway HTTP 反向代理。透传 /v1/* 请求，注入 Bearer Token，支持 SSE 流透传，健康检查端点。
proxy.js — 88 行
sse-manager.js
SSE 连接池管理。客户端注册/注销，广播 Gateway 状态与 Agent 变更事件，死连接清理。
sse-manager.js — 66 行
fs-store.js
文件系统存储层。openclaw.json 读写（原子写入 via tmp+rename），Agent 配置管理，Session JSON 持久化，Skill 目录扫描（global / extraDirs），路径安全校验（_isPathWithinAllowedRoots），工作目录清理。
fs-store.js — 420 行
agent-routes.js
Agent CRUD API。创建/更新/删除 Agent，Skill 绑定/解绑，AGENTS.md/TOOLS.md 读写，30s 缓存，工作目录自动重命名。
agent-routes.js — 429 行
roster-sync.js
Agent Roster 同步引擎。Skill symlink/junction 管理，allowAgents 引用完整性校验，TOOLS.md 系统段落同步（团队成员 + 技能），IDENTITY.md / BOOTSTRAP.md 自动生成。
roster-sync.js — 386 行

04 — 核心数据流 / MESSAGE FLOW (CHAT COMPLETION)
1. 用户输入
ChatController.sendMessage()
2. 构建请求
MessageBuilder → Api.chat()
3. 代理转发
proxy.js → Gateway :18789
4. SSE 流式响应
text/event-stream → delta
5. 渲染输出
StreamRenderer → DOM
子 Agent 调度流 (Dispatch Mode)
main Agent 调用 sessions_spawn → SSE [DONE] → 前端进入 dispatching 状态
→ Gateway WS 推送 session.tool / sessions.changed 事件
→ server.js 广播 subagent-progress / subagent-done SSE 事件
→ session-sync.js 增量读取 JSONL → 广播 announce-result SSE
→ ChatController.handleAnnounceResult() 渲染子 Agent 回复

06 — 技术评估 / TECHNICAL ASSESSMENT
架构模式
BFF 代理层
Web Server 作为 Browser 与 OpenClaw Gateway 之间的 BFF（Backend For Frontend），承担静态资源、API 聚合、SSE 桥接、会话持久化职责。轻量且职责清晰。
运行时依赖
1 个 npm 包
仅依赖 ws（WebSocket 客户端）。HTTP 服务器使用 Node.js 原生 http 模块，前端零框架（Vanilla JS + marked + DOMPurify）。极端轻量。
代码规模
~3,500 行
后端约 2,300 行（8 个核心文件），前端约 1,200 行（不含组件）。单文件模块，无构建流程，即开即用。
通信协议
三路通道
HTTP/SSE 对话流式输出
WebSocket Gateway 事件订阅
SSE 前端实时推送
安全设计
多层防护
DOMPurify XSS 防护，上传文件扩展名白名单，Session ID 路径遍历校验，请求体 10MB 上限，openclaw.json 原子写入（tmp+rename），路径白名单校验。
Agent 系统
多 Agent 协作
支持 main + 子 Agent 架构，sessions_spawn 智能调度，Skill symlink 管理，TOOLS.md 自动同步，allowAgents 权限控制，Roster 完整性校验。
