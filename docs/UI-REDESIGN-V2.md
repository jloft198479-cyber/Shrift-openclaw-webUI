# 虾指挥 OpenClaw — UI 视觉重设计方案 v2.0

> **定位**：AI 助手聊天工具
> **设计参考**：Claude 聊天界面的设计语言（参考设计元素，非 1:1 照搬）
> **核心策略**："消失的界面" — UI 退到幕后，文字内容成为唯一主角

---

## 一、从 Claude 截图提取的设计语言

从截图分析，Claude 聊天界面的核心视觉特征：

| 特征 | 观察结果 |
|------|---------|
| **整体色调** | 极度克制的灰色系，接近纯白，几乎没有彩色元素 |
| **侧边栏** | 浅灰背景（约 #F5F5F5），与主区域无明显 border，靠极浅灰度差自然过渡 |
| **消息气泡** | **用户和 AI 消息都没有气泡背景**，直接在白色/浅灰底上排列 |
| **消息区分** | 用户消息右对齐 + 灰色文字；AI 消息左对齐 + 深色文字 |
| **输入区** | 极简，无明显容器包裹，几乎融入背景 |
| **间距** | 极大留白，消息之间间距宽松 |
| **品牌色** | 仅 logo 和极少量点缀使用品牌色，不作为主视觉元素 |

### 设计哲学提炼

**Claude 的设计核心是"消失的界面"**：
- 不用气泡、边框、卡片去"框"内容
- 不用品牌色去"染色"界面
- 不用装饰去"填充"留白
- 让灰度和排版来建立层级，而不是颜色和边框

---

## 二、设计策略 — 借鉴 Claude，保留虾指挥品牌个性

**借鉴什么：**
- ✅ 无气泡消息布局（消失的界面）
- ✅ 大面积留白 + 居中消息流
- ✅ 极简侧边栏（灰度差分隔，无 border）
- ✅ 极简输入区（无重容器包裹）
- ✅ 克制的色彩使用（灰色为主，品牌色极少量点缀）

**保留虾指挥的个性：**
- ✅ 赤陶色作为品牌色（Claude 用橙色，我们用赤陶色）
- ✅ Agent 多助手功能（Claude 没有，这是我们的差异化）
- ✅ 代码块深色标题栏（Claude 也有类似处理）
- ✅ 中文优先的排版（字号/行高需要比英文更大）

**不做 1:1 照搬：**
- ❌ 不抄 Claude 的具体色值
- ❌ 不完全去掉侧边栏的视觉分隔（中文 UI 需要比英文更明确的区域划分）
- ❌ 不去掉所有品牌色——保留赤陶色作为 logo 和关键交互元素的点缀

## 三、配色系统

### 设计思路

Claude 用的是**冷灰色系**（偏蓝的灰），整体极其干净。我们不需要照搬这个色温，但需要学习它的**克制程度**。

虾指挥用**中性偏暖的灰色系**——不是之前 v2.0 方案里那种明显的棕调暖灰，而是**中性灰带极微暖调**，既有品牌温度又不偏离"消失的界面"原则。

### 完整色板

```css
:root {
  /* ── 灰色系（中性偏暖，克制使用） ─── */
  --gray-50:  #FAFAFA;   /* 页面主背景：极浅灰，接近白但不是纯白 */
  --gray-100: #F5F5F5;   /* 侧边栏背景：与主区域只有 1 级灰度差 */
  --gray-200: #EEEEEE;   /* hover 背景、微妙分隔 */
  --gray-300: #E0E0E0;   /* 边框（极少量使用） */
  --gray-400: #BDBDBD;   /* 占位符文字 */
  --gray-500: #9E9E9E;   /* 次要文字、时间戳 */
  --gray-600: #757575;   /* 辅助文字 */
  --gray-700: #424242;   /* AI 消息正文 */
  --gray-800: #212121;   /* 标题、强调文字 */
  --gray-900: #121212;   /* 最深文字 */

  /* ── 品牌色（赤陶色，极少量使用） ─── */
  --accent:        #C96442;   /* 仅用于 logo、发送按钮、极少量交互高亮 */
  --accent-hover:  #B55A38;
  --accent-subtle: #FAF5F2;   /* 极淡底色：用于选中状态、激活指示 */
  --accent-text:   #C96442;

  /* ── 语义色 ─── */
  --success:  #4CAF50;
  --warning:  #FF9800;
  --error:    #F44336;

  /* ── 表面 ─── */
  --surface:       #FFFFFF;   /* 卡片、输入框背景 */
  --surface-hover: #F5F5F5;   /* 表面 hover */

  /* ── 边框（极少使用） ─── */
  --border: #E0E0E0;          /* 只在输入框和代码块等必要位置出现 */
}
```

### 与 P0 和 v2.0 的对比

| 变量 | P0（旧） | v2.0（暖灰） | 最终方案 |
|------|---------|-------------|---------|
| 背景 | `#F9FAFB` 冷灰 | `#FAFAF8` 明显暖灰 | `#FAFAFA` 中性灰 |
| 侧边栏 | `#F3F4F6` 冷灰 | `#F5F4F1` 明显暖灰 | `#F5F5F5` 中性灰 |
| 边框 | `#E5E7EB` 冷灰 | `#EAE8E4` 暖灰 | `#E0E0E0` 中性灰 |
| Accent | `#D97706` 琥珀橙 | `#C96442` 赤陶色 | `#C96442` 赤陶色（保留） |
| **品牌色用法** | 到处用 | 大量气泡用 | **极少量点缀** |

**关键转变**：品牌色从"主视觉元素"降级为"点缀元素"。参考 Claude 的做法——品牌色只在 logo 和关键操作按钮上出现，不染背景、不做气泡。

## 四、排版系统

### 字体

```css
--font: "Inter", "Noto Sans SC", -apple-system, BlinkMacSystemFont, sans-serif;
--font-mono: "JetBrains Mono", "SF Mono", "Cascadia Code", monospace;
```

### 字号

| 用途 | 当前值 | 新值 | 理由 |
|------|-------|------|------|
| 消息正文 | 13px | **16px** | Claude/ChatGPT 标准，中文需要更大 |
| 消息行高 | 1.6 | **1.75** | 16px × 1.75 = 28px，中文阅读舒适线 |
| 侧边栏文字 | 13px | **13px** | 辅助区域，保持小 |
| 输入框 | 14px | **15px** | 略小于正文，不抢视觉权重 |
| 代码块 | 13px | **13.5px** | 代码需要小于正文以区分层级 |
| 欢迎标题 | 22px | **24px** | 大而简洁 |
| 欢迎副标题 | 14px | **15px** | 灰500，陪衬角色 |

## 五、布局设计

### 5.1 侧边栏 — 最重要的区域，独立详细设计

Claude 的侧边栏特点：浅灰背景，与主区域无可见 border，列表项极度简洁（只有文字，无 icon 无 badge 无 meta）。它是「抽屉」而不是「控制面板」。

但虾指挥有 Agent 多助手功能，比 Claude 侧边栏复杂。我们不能照搬 Claude 的极简——需要找到「Claude 的安静感」和「虾指挥的功能密度」之间的平衡点。

#### 当前侧边栏的问题诊断

| 问题 | 具体表现 | 为什么不对 |
------|---------|------------|
| **accent 色太抢** | 新对话按钮虚线边框 + accent 背景 + accent 文字；筛选栏 active 状态也是 accent；Agent 区域标题 accent 色 | Claude 几乎不用品牌色，侧边栏里更没有。这些 accent 元素把视线从消息区拉到侧边栏 |
| **信息层级混乱** | logo 标题 22px 粗体、新对话按钮 16px 粗体 accent、「虾内助」16px 粗体——三个视觉权重一样高 | 侧边栏应该只有一个视觉主角：**会话列表**，其他都是配角 |
| **新对话按钮太重** | 虚线边框 + accent 背景 = 一个「CTA 按钮」的视觉重量 | 这不是落地页，不需要 CTA。Claude 的新对话就是一个极简的 item |
| **筛选栏多余** | 「全部」和「待办」两个 tab 占了一行 | 只有 2 个选项的 tab 不需要做成 tab，一个 toggle 或直接在列表标题旁边就够了 |
| **Agent 区域太重** | section-title 16px 粗体 + section-count badge + new-agent-btn（虚线 accent）+ skill-tag | 助手列表应该是侧边栏的第二层，比会话列表更安静 |
| **session item 太胖** | icon(20px) + agent-badge + name + meta + menu-btn，单行堆了 5 个元素 | 信息密度太高，每个 item 都在抢注意力 |
| **折叠按钮突兀** | 悬浮在侧边栏右边缘，24px 圆形 + border + accent hover | 破坏侧边栏的「安静」感 |

#### 新侧边栏设计

```
┌─ 侧边栏（240px，#F5F5F5）─────────────┐
│                                      │
│  🦞 虾指挥              [← 折叠]       │  ← header: 极简，logo+名称+折叠按钮一行
│                                      │
│  + 开始新对话                         │  ← 新对话: 不是按钮，是一个 item，和会话列表同款
│                                      │
│  ──────────────────────────────       │  ← 不是 border，是视觉呼吸
│                                      │
│  最近对话                             │  ← 区块标题: 12px 灰色，不粗体，不 accent
│                                      │
│    前端项目讨论                        │  ← session item: 纯文字，无 icon 无 badge
│    写周报                             │     13px，深灰，单行截断
│    代码审查                            │     hover: 极淡灰背景
│    学习笔记                            │     active: 左侧 2px accent 指示条 + 极淡底色
│                                      │     无 meta 时间，无 agent badge
│                                      │
│  ──────────────────────────────       │
│                                      │
│  助手                                │  ← 区块标题: 12px 灰色，与「最近对话」同款
│                                      │
│    🤖 前端开发者                       │  ← agent item: emoji icon + 名称，无 meta 无 skill-tag
│    🤖 Python工程师                    │     单行，紧凑
│    🤖 私域运营师                       │
│                                      │
│                           [+ 新建]    │  ← 新建助手: 极淡文字按钮，不是 accent 虚线
│                                      │
└──────────────────────────────────────┘

侧边栏右边: box-shadow: 1px 0 0 rgba(0,0,0,0.04)
（几乎看不见的分隔线）
```

#### 侧边栏各元素详细设计

**① Header（品牌标识）**
```
当前:  logo + h1(22px semibold accent?) + restart-btn(28px)
新方案: logo + 名称(14px medium gray-700) + 折叠按钮（移到 header 里，不再悬浮）
```
- 去掉重启按钮（或移到 dropdown 里，不占 header 位置）
- 标题字号从 22px 降到 14px，和侧边栏文字同量级——侧边栏不需要「大标题」
- 折叠按钮从「悬浮在右边缘」改为「header 右侧的小 icon」，不再有 border + accent hover
- padding: 16px 16px 12px

**② 新对话**
```
当前:  <button> 虚线边框 accent 背景 accent 文字 16px semibold
新方案: <div class="session-item new-chat"> + 前缀 + 开始新对话
```
- **做成和会话 item 同款**，不是一个 CTA 按钮
- 前缀用 `+` 或铅笔 icon，灰色，不是 accent
- hover 时和 session item 一样：极淡灰背景
- 这样侧边栏的「新对话」和「最近对话」形成自然列表，没有视觉打断

**③ 筛选栏 → 去掉独立行**
```
当前:  两个 filter-btn 横排占一行
新方案:  在「最近对话」标题旁边放一个小的 toggle 或文字链接
```
- 只有 2 个选项（全部/待办），不值得做成 tab
- 方案 A：在「最近对话」标题右侧加一个「待办」文字链接，点击切换
- 方案 B：直接在 session list 顶部加一行细字「显示全部 / 显示待办」
- 省出的一行空间给会话列表

**④ 会话列表**
```
当前:  icon + agent-badge + name + meta(时间) + menu-btn(⋯)
新方案:  name（单行）+ menu-btn（hover 显示）
```
- **去掉 icon**：会话列表不需要 icon——Claude 也没有
- **去掉 agent-badge**：用颜色或细字区分 agent 对话即可，不需要占位的 badge
- **去掉 meta 时间**：Claude 也不显示时间——最近的对话放最上面就够了
- menu-btn 保留，但更轻：24px，opacity:0 默认，hover 时显示
- active 状态：`background: var(--gray-200)` + 左侧 2px `var(--accent)` 指示条（不是 box-shadow inset，是真正的 border-left 或伪元素）
- item 间距：从 margin-bottom:4px 改为 2px，列表更紧凑
- 整体 padding：上下 4px，不再 8px

**⑤ Agent 区域**
```
当前:  section-title(16px semibold) + section-count(badge) + new-agent-btn(accent虚线)
新方案:  标题(12px regular gray-500) + 助手列表 + 新建助手(极淡文字)
```
- 标题「虾内助」改「助手」，12px，regular（不是 semibold），gray-500
- 去掉 section-count badge
- 去掉 new-agent-btn 的虚线 accent 样式，改为和会话列表「+ 开始新对话」同款的极简 item
- agent item：emoji icon(20px) + 名称(13px)，单行，紧凑
- 去掉 agent-meta（描述、skill-tag）——在侧边栏里不需要这些信息
- agent item 间距 2px
- section 的 border-top：1px solid rgba(0,0,0,0.06)，极淡

**⑥ 折叠按钮**
```
当前:  悬浮在侧边栏右边缘，position:absolute，24px 圆形，border + accent hover
新方案:  header 右侧的 20px icon 按钮，无 border 无 accent
```
- 从悬浮绝对定位改为 header 流内布局
- 无 border，无 background
- hover: color 变深，不需要 accent 色

**⑦ 侧边栏背景与分隔**
```
当前:  border-right: 1px solid var(--border)
新方案:  无 border，box-shadow: 1px 0 0 rgba(0,0,0,0.04)
```
- Claude 的做法：侧边栏和主区域之间没有可见的线
- 我们用一个极微的 shadow 代替 border——几乎看不见，但暗示分隔

**⑧ 滚动条**
- 宽度 4px（当前 6px）
- thumb 颜色 rgba(0,0,0,0.1)，hover 时 rgba(0,0,0,0.15)
- 更安静，不抢注意力

### 5.2 消息区域 — 无气泡布局

**核心变化：去掉消息气泡**

当前 UI 用户消息有灰色背景气泡，AI 消息有白色背景气泡——这跟 Claude 的"消失的界面"完全相反。

**新布局**：
```
                         消息区域（#FAFAFA）
                    ┌─────────────────────┐
                    │                     │
                    │  Claude 回复在这里    │  ← 左对齐，深色文字，无背景
                    │  没有 bubble，       │
                    │  没有边框，          │
                    │  没有圆角。         │
                    │  就是文字。          │
                    │                     │
                    │         用户消息在这里 │  ← 右对齐，灰色文字，无背景
                    │                     │
                    │                     │
                    │  Claude 又回复了      │  ← 左对齐
                    │                     │
                    └─────────────────────┘
                    居中，max-width: 720px
```

**区分方式**：
- **AI 消息**：左对齐，`color: var(--gray-700)`，包含 avatar/名字
- **用户消息**：右对齐，`color: var(--gray-600)`（比 AI 稍浅），包含"你"标签
- **两者都没有背景色、边框、圆角**

**为什么这样做**：
- Claude 截图已经验证：无气泡 = 更干净、更专注
- 去掉气泡后，代码块、表格、列表等 Markdown 元素不会被"框住"，视觉层级更清晰
- 减少视觉噪音，让用户注意力集中在文字内容上

### 5.3 输入区 — 极简容器

**Claude 风格**：输入框几乎融入背景，没有明显的卡片容器感。

```
                    ┌─ 输入区域 ─────────────────────┐
                    │ [📎]  输入你的问题...     [发送▶] │  ← 极细边框或无
                    └────────────────────────────────┘
                    padding: 12px 16px
                    max-width: 720px, 居中
                    border: 1px solid var(--gray-200)  ← 极淡
                    border-radius: 24px               ← 大圆角但不是胶囊
                    background: var(--surface)
```

**与当前的区别**：
- 去掉厚重的外边框和明显的容器感
- 边框色极淡（`#EEEEEE`），hover 时才稍微加深
- 圆角加大到 24px，但不是完全的胶囊形
- 不用 `box-shadow`（Claude 的输入区没有阴影浮起感）
- 发送按钮：圆形小按钮，`accent` 色，在输入框右侧内部

### 5.4 欢迎页 — 极致留白

```
              [页面垂直居中]

               🦞  虾指挥          ← logo + 品牌名，极简
                                  
            今天想聊点什么？        ← 15px，gray-500
                                  
          ┌──────────────────┐
          │ 帮我写一封邮件     │     ← 3 个快捷建议
          │ 分析这份数据      │       灰色文字，hover 变深
          │ 搜索最新资讯      │
          └──────────────────┘
          
          内容宽度 max-width: 480px
          垂直位置约 40%
```

## 六、阴影体系 — 极简

Claude 几乎不用阴影。我们只在极少数场景使用：

```css
--shadow-xs:  0 1px 2px rgba(0,0,0,0.03);   /* dropdown */
--shadow-sm:  0 2px 8px rgba(0,0,0,0.06);   /* modal */
--shadow-md:  0 4px 16px rgba(0,0,0,0.10);  /* 代码块（深色背景需要） */
```

**原则**：能不用阴影就不用。用灰度差和间距来建立层级，而不是阴影。

| 按钮 | 8px | **8px** | 保持，不需要改 |
| 代码块 | 12px | **12px** | 保持 |
| dropdown | 12px | **12px** | 保持 |
| modal | 16px | **16px** | 保持 |
| **消息气泡** | 12px | **无** | **去掉气泡** |

## 八、动效体系

| 场景 | 动效 | 时长 | 备注 |
|------|------|------|------|
| 消息出现 | `opacity: 0→1` | 200ms | 极简淡入，不加 translateY |
| hover | `background-color` | 150ms | 微妙变化 |
| 侧边栏折叠 | `width` 过渡 | 200ms | 保持 |
| 流式光标 | 竖线闪烁 | 1s | 保持 |
| dropdown | `opacity + scale(0.98)` | 150ms | 极微缩放 |
| 代码复制成功 | ✓ 图标 | 300ms | 保持 |

**原则**：Claude 的动效极度克制。不做花哨的入场动画，不做弹跳效果。淡入就是最优雅的出场。

## 九、代码块

代码块是唯一需要"容器感"的元素（因为需要与正文明确区分）：

```
┌─ javascript ──────────────── [📋] ─┐
│                                      │
│  const greeting = "Hello!";          │  深色背景 #1E1E1E
│  console.log(greeting);              │  浅色文字 #D4D4D4
│                                      │
└──────────────────────────────────────┘
```

- 整体圆角 12px

## 十、Agent 模式指示

虾指挥有 Agent 多助手功能，这是差异化。需要一种自然的视觉指示：

```
  ┌─ 消息区域顶部 ──────────────────────────┐
  │  [🤖 前端开发者 ✕]                       │  ← pill 标签，极淡背景
  │                                         │
  │  AI 回复...                              │
  └─────────────────────────────────────────┘
```

- pill 背景：`var(--accent-subtle)` — 极淡赤陶色
- pill 文字：`var(--accent)` — 赤陶色
- 位于消息区顶部，不在主内容流中抢视觉

## 十二、验收标准

1. **打开页面的第一感觉**：干净、安静、留白充足，像 Claude 那样"界面消失了"
2. **消息区域**：没有气泡，用户消息靠右灰色，AI 消息靠左深色
3. **侧边栏**：与主区域无明显分隔线，灰度差自然过渡
4. **输入区**：极简，不抢注意力
5. **品牌色**：只出现在 logo、发送按钮、选中指示上，不染色背景
6. **阅读舒适**：16px 正文 + 1.75 行高
7. **与 P0 的视觉差异**：一眼就能看出不是同一个设计
