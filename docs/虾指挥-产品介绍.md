# 虾指挥 — OpenClaw Web UI

> 让每个用户都能轻松指挥一支 AI 专家团队

---

## 一句话介绍

虾指挥是一款基于 OpenClaw 的 Web UI，主打Agent的主从模式的显示调用，除了结合了openclaw原生的智能调度模式，最大的特点是实现了和子agent一对一的交互，整体体验友好

---

## 核心场景

### 场景一：智能调度（主 Agent 自动分配）

```
用户：帮我写一篇关于 AI 的爆款文案
       ↓
主 Agent：收到，我来安排
       ↓
主 Agent 自动 spawn 咪蒙（文案专家）
       ↓
咪蒙：搜索知乎热点 → 撰写文案 → 保存文件
       ↓
用户：收到成品，直接使用
```

**特点**：用户只需描述任务，主 Agent 自动判断应该交给哪个子 Agent。

---

### 场景二：独立交互（用户直接指定）

```
用户：@小周 搜索知乎上关于 AI Agent 的讨论
       ↓
系统：直连小周（知乎搜索专家）
       ↓
小周：执行搜索 → 返回结果
       ↓
用户：看到真实的搜索结果
```

**特点**：用户明确指定要找哪个"专家"，直接对话，精准高效。

## 核心特点

### 1. 显式主从模式

| 模式       | 说明                        | 适用场景       |
| -------- | ------------------------- | ---------- |
| **智能调度** | 主 Agent 自动分配任务给合适的子 Agent | 复杂任务、多步骤流程 |
| **独立交互** | 用户通过 @指定某个子 Agent 直接对话    | 精准需求、单点任务  |

### 2. 子 Agent = 专家工具集

每个子 Agent 是一个"专家"，由三部分组成：

- **身份设定**：名称、描述、头像
- **技能绑定**：搜索、翻译、文案、PPT 等具体能力
- **模型匹配**：选择最适合的大模型

创建完成后，子 Agent 自动注册到系统，主 Agent 可随时调用。

### 3. 自动注册，创建即用

用户创建子 Agent 时，系统自动完成：

- ✅ 写入配置文件（openclaw.json）
- ✅ 创建专属工作区目录
- ✅ 同步花名册（AGENTS.md），让主 Agent 认识新成员
- ✅ 注册到白名单（allowAgents），确保可被调用

**用户无需手动配置任何文件。**

### 4. 极简体验

> **用户视角：傻瓜式操作，不需要思考底层逻辑**
> **技术视角：稳定架构，组件化设计，高内聚低耦合**

## 典型使用流程

### 第一步：创建子 Agent

```
点击"新建 Agent"
  → 设置名称：小周
  → 设置描述：擅长在知乎寻找答案
  → 绑定技能：zhihu-search
  → 选择模型：DeepSeek V4 Flash
  → 点击"完成"
  → 系统自动注册，小周立即可用
```

### 第二步：使用子 Agent

**方式一：智能调度**

```
用户：帮我搜索知乎上关于 AI Agent 的最新讨论
主 Agent：判断任务类型 → 自动 spawn 小周
小周：执行搜索 → 返回真实结果
```

**方式二：直接指定**

```
用户：@小周 搜索知乎上关于 AI Agent 的最新讨论
系统：直连小周
小周：执行搜索 → 返回真实结果
```

## 与传统多 Agent 系统的区别

| 维度         | 传统多 Agent   | 虾指挥           |
| ---------- | ----------- | ------------- |
| 调度方式       | 完全自动，用户无法干预 | 自动 + 手动，用户可选择 |
| 子 Agent 创建 | 开发者配置       | 用户自助创建        |
| 用户感知       | 黑盒，不知道谁在干活  | 透明，知道谁在处理     |
| 资源消耗       | 可能过度调度      | 精准调用，按需分配     |

## 总结

虾指挥的核心价值：

1. **显式主从模式**：用户可以选择让主 Agent 自动分配，或直接 @指定子 Agent
2. **专家工具集**：每个子 Agent 是一个"专家"，绑定特定技能，各有所长
3. **自动注册**：创建即用，无需手动配置
4. **极简体验**：前端极简如水，后端硬核如钢
