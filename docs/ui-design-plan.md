# 虾指挥 Web UI — 设计优化方案

> 来源：UI/UX Pro Max 技能评估
> 日期：2026-05-28
> 当前状态：待实施

---

## 一、产品定位

AI/Chatbot 管理面板 + SaaS 工具，目标用户为开发者和 AI 使用者。

## 二、设计方向

风格：AI-Native UI × Minimalism

品牌关键词：轻量、智能、干净、专注

## 三、色彩体系（保留）

**主色调确认保留当前配色**（赤陶色系，Claude 风格）：

| 角色 | 色值 | 用途 |
|------|------|------|
| Primary | `#C96442` | 主色 / 按钮 / 链接 |
| Primary Hover | `#B3573A` | 悬停状态 |
| Primary Light | `#FDF2ED` | 浅色背景 / 激活项 |
| Surface | `#FFFFFF` | 卡片 / 侧边栏 |
| Sidebar | `#F8FAFC` | 侧边栏背景（待改）|
| Background | `#F1F5F9` | 页面背景（待改）|
| Text Primary | `#0F172A` | 主文字（待改）|
| Text Secondary | `#64748B` | 辅助文字（待改）|
| Border | `#E2E8F0` | 边框 / 分割线（待改）|
| Success | `#10B981` | 成功 / 连接状态 |
| Destructive | `#EF4444` | 危险操作 |

**待改事项**：当前 CSS 使用自定色值（`--text-2: #706B66`、`--sidebar-bg: #EDEAE5` 等），后续改 CSS 变量映射到上述新色值。

## 四、布局调整

- 侧边栏宽度 240px → 220px
- 消息区最大宽 760px → 720px
- 侧边栏底色从暖灰改为冷灰，降低视觉重量
- 主背景改浅灰底，让白色卡片更突出

## 五、组件级优化

### 侧边栏（高优先级）
- [ ] 折叠按钮悬停效果改进

## 八、快速见效项

优先做这些改动小、效果大的：

1. 侧边栏底色 `#EDEAE5` → 浅冷灰
2. 主背景 `#FAF9F7` → `#F1F5F9`
3. AI 气泡增强（浅色背景 + 微阴影）
4. placeholder 文案 "向虾指挥提问…"
5. 右上角 WebSocket 连接状态指示器
